# Cuaderno de español

A 29-day Spanish speaking workbook (Day 2 → Day 30, 8 September – 6 October 2026). Each day is a full lesson: goals, grammar, translations with keys, fill-in-the-blank drills, vocab, sentence upgrades, speaking prompts, and a timed final monologue.

Progress is stored in your browser (localStorage). Nothing is sent to a server.

## Daily method

1. **Duolingo** — the unit named in that day’s notes. Say every sentence out loud.
2. **Language Transfer** — pause and answer before the narrator does.
3. **This workbook** — grammar, translations, blanks, vocab, upgrades.
4. **Speaking** — every prompt out loud, then the final timed monologue.
5. **Dreaming Spanish + SpanishDict** — one video on the day’s theme, then the listed vocab.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:44721](http://localhost:44721).

```bash
npm run build
npm start
```

## What’s in here

| Week | Dates | Focus |
| --- | --- | --- |
| 1 | 8–13 Sept | Present tense, gustar, questions, adjectives |
| 2 | 14–20 Sept | Reflexives, preterite, imperfect, direct object pronouns |
| 3 | 21–27 Sept | Double pronouns, future, conditional, commands, por/para |
| 4 | 28 Sept – 6 Oct | Subjunctive, relative pronouns, si clauses, connectors, final exam |

Mark a day complete when you have spoken the final topic. Come back to any day from the calendar.
